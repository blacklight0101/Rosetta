The decision log records **what** the product owner decided, one row per decision. This journal summarises each
working session: the topics, the outcome and why, with links to the decisions and questions (DEC-33, DEC-38). The
conversation itself is kept privately by the owner and is never published here.

Rules:

- One file per working session: `YYYY-MM-DD-<topic>.md`; a second session on the same day adds a suffix.
- A curated summary, never a conversation or a transcript: no quotes, no secrets, no credentials, no personal data,
  nothing about the owner's employer or its systems.
- Append only. A correction is a new dated note at the end of the entry, never an edit of what was recorded.
- Every decision mentioned links its `DEC-nn`; every open question its `Q-nn`.
