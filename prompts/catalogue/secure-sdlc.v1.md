## Rule

Build security activities into every phase: requirements, design, code review, testing, release and operation.

## Why it matters

Security becomes routine work spread across the project instead of a single audit that arrives too late to
change the design.

## How to check

Each phase of the roadmap names its security activity; dependency and secret scanning run in CI; findings are
tracked to closure like any other defect.
