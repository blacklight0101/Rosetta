## Rule

Have the agent propose a plan for each task and agree it before any code is written.

## Why it matters

A short plan catches misunderstandings while they are cheap and keeps the agent inside the task's scope.

## How to check

Each task card or pull request links the agreed plan; changes outside the plan are flagged in review and
either justified or removed.
